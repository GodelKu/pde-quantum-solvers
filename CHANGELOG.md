# Changelog

## 0.2.0

After an independent review by a second model (Claude Fable 5.2). The review re-ran the report,
reproduced the claims with its own scripts (including problems the repository did not test), and
injected 18 bugs into the code to see which ones the test suite catches; 17 were caught.

Numerical fixes:

- **`fd4` was first order at hard walls.** Next to each wall the five-point stencil used `ψ = 0`
  at the node outside the box. That is harmless only when the state has decayed before the wall,
  which was true for the three potentials in the README and for nothing else: on the infinite
  well the observed order was 0.95, 0.99, 1.00. The ghost value now comes from the odd extension
  `ψ(−h) = −ψ(h)`; the order is 3.99, 4.00, 4.00. New hard-wall tests (infinite well, linear ramp
  with Airy-zero levels) measure the order of every Dirichlet solver, and the README shows them.
- **The heat-equation benchmark was unfair.** `heat_solve` rebuilt and refactorised the constant
  step matrix (and the IC(0) factor) at every step, while the multigrid hierarchy was built once
  and outside the timer. The README concluded that plain CG was the fastest. Every solver is now
  set up once per run and the setup is timed with it: the factored direct solve, 0.201 s for 20
  steps in 0.1.0, now takes about 0.02 s and is the fastest of the four in the committed run.
- **The double-well dynamics check was not independent.** It started from the eigenvectors of the
  same Fourier Hamiltonian that the propagator uses and timed the first minimum of `P(x < 0)`.
  Its agreement of 3.25e-06 with the stationary splitting was accidental: the splitting of the
  Strang propagator itself differs by 1.98e-04 at `dt = 0.02`. The packet now starts as a Gaussian
  built without an eigensolver, the frequency is fitted to the filtered `P(x < 0, t)`, and the
  reference is the Chebyshev solver. The fit reproduces the propagator's eigenphase splitting,
  and the difference to Chebyshev falls as `dt²`.
- **The wave-packet "abs difference" was presented like an error.** It is not converged: read later
  on a longer box it changes size and sign. The column is now signed, the README says what it
  supports, and a generated table shows the dependence on the measurement time.

Tests and reproducibility:

- IC(0) had no correctness test (dropping a term of the factor left all tests green). Tests now
  check `L Lᵀ = A` on the sparsity pattern, that `L` has the pattern of `tril(A)`, that applying the
  preconditioner is plain triangular substitution, and pin the iteration counts.
- Every README table is rendered from `docs/results/results.json`; `tests/test_readme_sync.py`
  fails if they disagree and recomputes a few numbers from the code. `tools/fill_readme.py`
  refreshes the README without rerunning the studies.
- Wall times were single runs (Poisson: best of 3, while the README said single runs), with
  outliers up to ten times off (`numerov` 5004.6 ms in one table, about 500 ms in the others).
  Every wall time is now the median of 5 runs after a warm-up run, with the range. A new table
  shows that the cost of `fd4` is the eigenvector step of LAPACK's banded driver.
- The results recorded a kernel string and CPU count. They now record only the Python, NumPy and
  SciPy versions and the OS family.
- The README no longer says that the CI workflow never ran, and the remark about the Morse box
  is now a generated table instead of a note.
- The RK4 stability demonstration brackets the limit `2√2` (2.80 stable, 2.86 unstable) and
  shows the growth factor per step.

Smaller fixes:

- CG, multigrid and the direct solve return zero for a zero right-hand side (CG divided by
  `||b||`), so `heat_solve` from `u0 = 0` works.
- Crank–Nicolson's undershoot on discontinuous heat data is tested and stated in Limitations.
- Norm drift is labelled `abs(norm(t) − norm(0))`, as computed.
- The CLI rejects invalid values with an argparse error instead of a traceback, marks Morse levels
  above the bound states, and reports an unstable RK4 step.
- Docstrings: the CG stopping test uses the recursive residual; the FD scattering error also
  comes from the lattice dispersion outside the barrier; the grid's walls are at `−L/2 − h` and
  `+L/2`; no ILU baseline exists.
- CI runs on Linux, macOS and Windows with Python 3.10 to 3.13, with read-only permissions and
  pinned versions of pytest, ruff and mypy.
- [docs/ROADMAP.md](docs/ROADMAP.md): five planned extensions, each with a strict `xfail` test.

## 0.1.0

- Six stationary solvers (`fd2`, `fd4`, matrix Numerov, Fourier, Chebyshev, shooting), three
  propagators (Crank–Nicolson, split-step Fourier, RK4), barrier tunnelling, and Poisson and heat
  solvers with CG, IC(0) and multigrid.
- Convergence studies, figures and README tables generated by `pdeqs report`.
